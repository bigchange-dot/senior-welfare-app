# 앱 점검 (2026-11-17)

전체 검토 4번 단계. 대상: 미커밋 v1.4.1 코드(디버그 빌드). 기기: Lenovo 태블릿 TB336FU(Android 16) 실기기 +
같은 기기에서 폰 화면(1080×2400, 420dpi)과 글자 크기 2.0배를 흉내 내 확인. 정적 분석 `flutter analyze`: 오류·경고 0 (const 권고 13건).

## 1. 기능 버그 (먼저 고칠 것)

| # | 문제 | 근거 | 고칠 방향 |
|---|---|---|---|
| 1 | **앱이 꺼진 상태에서 알림을 누르면 공고가 아니라 홈이 열림** | `main()`이 `runApp()` 전에 `FcmService.initialize()`를 기다리고, 그 안에서 `getInitialMessage()` → `navigatorKey.currentState?.pushNamed()`. 이 시점엔 네비게이터가 없어 무시됨 (코드 확인. 기기 재현은 아래 4번 사유로 못 함) | 첫 메시지를 저장해 두고 첫 화면이 그려진 뒤(`addPostFrameCallback`) 이동 |
| 2 | **알림 토큰을 못 받으면 알림 설정 전체가 건너뛰어짐** | `initialize()`가 한 `try` 안에서 `getToken()`(디버그 출력용) → 토픽 구독 → 알림 탭 처리기 등록 순. 토큰에서 예외가 나면 뒤가 전부 생략. 기기에서 `FIS_AUTH_ERROR`로 실제 발생 확인. 첫 실행을 인터넷 없이 하면 같은 일이 생길 수 있음 | `getToken()`을 따로 감싸거나 제거, 토픽 구독·처리기 등록은 항상 실행 |
| 3 | **인터넷 없이 처음 열면 "아직 등록된 공고가 없습니다"** | 저장된 데이터가 없으면 Firestore가 오류 대신 빈 결과를 줌 (기기 재현). 인터넷이 돌아온 뒤 당겨서 새로고침 2회로도 안 돌아오고, 필터 칩을 눌러야 회복 | 빈 결과가 캐시에서 온 것(`metadata.isFromCache`)이면 "인터넷 연결을 확인해 주세요" + 다시 시도 버튼, 새로고침은 서버에서 다시 받기 |
| 4 | **앱바의 새로고침 아이콘이 버튼이 아님** | `main.dart` — `Icon`만 있고 눌러도 동작 없음 | 새로고침 버튼으로 바꾸거나 제거 |

## 2. 어르신 사용성

| # | 문제 | 근거 |
|---|---|---|
| 5 | 찜(하트) 터치 영역이 작음 | 28px `GestureDetector`. 권장 48 미만이라 빗나가면 카드가 눌려 상세가 열림 |
| 6 | 시간("3일 전")·출처 배지 글자 14px | 앱 기준(본문 18px 이상)보다 작음. 글자 크기 2.0배에서는 커지지만 기본 설정에선 작음 |
| 7 | 목록 배너 광고에 "광고" 표시 없음 | 공고 카드 바로 아래 같은 폭(320×100). 테스트 광고엔 "테스트 광고" 표시가 붙지만 실광고엔 없음 → 공고로 착각해 누를 수 있음 |
| 8 | 필터 칩 17개, 가로 스크롤 | 처음 화면엔 3~11개만 보여 옆으로 넘겨야 함. 강북(수집 제외)·강서·동작·관악(6개월 0건)은 눌러도 "공고가 없습니다" |
| 9 | 설정의 지역 선택 설명이 알림을 언급하지 않음 | "선택한 지역의 복지 공고를 찜 탭에서 모아볼 수 있어요" — 실제로는 **어느 지역 알림을 받을지**도 정함. 알림 켜기/끄기는 화면 맨 아래 |
| 10 | 공고 상세가 데스크톱 사이트 그대로 | 복지관 사이트는 모바일 대응이 안 돼 메뉴·빈 공간 아래에 공고가 있고 글씨가 작음. 앱에서 할 수 있는 건 확대 기본값 정도 |
| 11 | 오래된 공고도 계속 보임 | 장애 기간 탓에 "29일 전" 공고가 최신 20건 안에 남음. 기간 지난 공고 표시가 없음 |

## 3. 정상 확인

- 실데이터 목록·카드 표시, 공고 상세(WebView) 열기, 뒤로 가기 시 전면 광고(테스트) → 닫으면 목록 복귀
- 배너 광고: 처음엔 늦게 떴지만 정상 표시 (320×100)
- 글자 크기 2.0배 + 폰 세로 화면: 화면 깨짐(오버플로) 없음. 하단 탭 글자("홈·찜·설정")는 커지지 않음
- 인터넷 끊김: 이미 받은 데이터가 있으면 그대로 보여 줌 (다만 오래된 데이터라는 표시가 없음)

## 4. 점검 환경 메모

- **로컬 빌드(디버그·업로드 키 서명)는 알림 토큰을 못 받는다** (`FIS_AUTH_ERROR`). `firebase_options.dart`의 Android API 키
  ("senior app api key")가 패키지 + SHA-1 `b4d1be8a…`(Play 앱 서명 키로 추정)로 제한돼 있기 때문.
  디버그 키 `3ebc1511…`, 업로드 키 `b7599c8c…`는 허용 목록에 없음. 알림 관련 확인은 Play 내부 테스트 트랙 빌드로 해야 한다.
- 이 이유로 1번(꺼진 상태 알림 탭)은 기기 재현 대신 코드로 확인했다.
- 스크린샷: 세션 임시 폴더 (커밋하지 않음)
