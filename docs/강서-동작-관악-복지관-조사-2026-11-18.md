## 3. 제안

1. **교체**: `scrape_gangseo`·`scrape_dongjak`·`scrape_gwanak`(구청) → 강서노인종합·마곡·사당·관악 4곳 (+ 동작노인종합은 선택 — 행정 공개가 대부분이라 규칙 필터가 거의 다 걸러 냄)
2. **방법**
   - 사당: `_scrape_g5_board` 그대로
   - 강서·마곡·관악: 짧은 주소형 게시판(`/notice`, 글은 `/notice/58`처럼) — 경기 조사에서 제안한 범용 목록 파서로 함께 처리하거나, 우선 사이트별 셀렉터로
   - 마곡: `backend/certs/intermediates.pem`에 중간 인증서 추가 (`http://crt.sectigo.com/ZeroSSLRSADVSSLCA2.crt`, 2035년 만료)
   - 복지관 출처라 `WELFARE_CENTER_SOURCES`에 이름 추가 (키워드 필터 대신 AI 판정)
3. **앱**: 연결하면 v1.4.1에서 뺀 강서·동작·관악을 `_filters`·`_regions`에 되살려야 함. v1.4.1 출시 뒤 다음 버전에서 함께
4. 구청 수집기를 지우기 전, 바꾼 출처로 2~3일 `SILENT_SAVE`로 돌려 판정 품질을 본다

## 4. 점검 방법
- 협회 목록 → 홈페이지 → '공지·소식·모집' 링크 → 날짜가 붙은 링크 수로 게시판 판정 → 최근 30일 글 수·규칙 필터 제외 수 (요청 사이 1초)
- 점검 스크립트는 세션 임시 폴더에만 있다
