## 1. 오늘의 운세 기능
> 2026-11-18 재설계 → `docs/운세-설계-2026-11-18.md` (출생연도·띠 선택, 하루 한 띠 공통 알림, AI 없이 문장 묶음). 아래는 옛 초안.

- 입력: 생년월일(양력/음력 선택). 음력은 `korean-lunar-calendar`로 양력 변환
- 일주: 2000-01-01 = 무오일(60갑자 인덱스 54) 기준 순환. 년주: 1984 = 갑자년, 입춘(약 2/4) 이전 출생은 전년도
- 길흉: 오늘 일진 천간과 사용자 일간의 십신 관계 + 일지 간 합/충
- 백엔드: 새벽 Cloud Scheduler → 운세 생성 함수(조합별 일괄, Gemini로 문장) → Firestore → 아침 FCM 발송
- 개인정보: 생년월일 원본은 기기에만, 서버엔 일주/년주 인덱스만
- 톤: 건강·가족·금전 위주, 불안 주는 표현 금지, "재미로 보는 운세" 고지

## 2. 전국 확장 (1차: 경기도)
- 경기 31개 시·군 대부분이 고시공고를 새올행정시스템(eminwon)에 게시 → 새올 파서 1개 + 도메인 목록으로 처리
- 일반구·읍면동 공고도 시 새올 목록에 함께 올라옴 → 구청 별도 수집 불필요, 공고번호 접두어로 하위 지역 분류
- 공고구분 04(일반공고), 05(채용)만 수집
- Gemini 호출 전 규칙 필터 필수 (공시송달·도로점용 등 잡음이 대부분, Gemini 무료 티어 분당 5회)
- 봇 차단 사이트는 우회하지 않고 제외
- 설정 초안: `docs/gyeonggi/gyeonggi_sources.yaml`
- 점검: `cd docs/gyeonggi && python3 probe_eminwon.py gyeonggi_sources.yaml` → 접근 실패한 곳만 홈페이지 목록 파서로 폴백
- 추가 확인: 서울 구청도 새올이면 기존 구청별 스크래퍼를 새올 파서로 통합 가능
