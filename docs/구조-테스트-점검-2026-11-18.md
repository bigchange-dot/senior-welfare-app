## 1. 테스트 — 추가함

점검 전: 백엔드 테스트 없음(pytest도 미설치), 프론트엔드는 Flutter 템플릿 테스트 1개뿐이었고 **항상 실패**(앱 전체를 Firebase 없이 띄움).

| `backend/tests/test_monitoring.py` | 10 | 헬스체크 판정 — 2026-10 Gemini 402 장애 상황을 그대로 넣어 알림이 나는지 |

- 실행: `cd backend && venv/bin/python -m pytest` (63개, 0.2초) / `cd frontend && flutter test` (3개)
- 네트워크·Firestore·LLM을 부르지 않는다 (가짜 DB·스크래퍼·LLM, `backend/tests/conftest.py`)
- 테스트 파일은 Functions 배포에서 제외 (`firebase.json` ignore)
- 프론트 테스트가 실제 문제를 하나 더 잡음: 글자 2배(선형) 좁은 폰에서 "서대문노인복지관" 배지가 잘림 → 두 줄까지 허용

LLM 판정 품질(프롬프트 변경 시 과거 판정과 비교)은 Ollama가 필요해 단위 테스트에 넣지 않았다. 2026-11-16~17 평가에 쓴 스크립트는 세션 임시 폴더에만 있다 — 필요하면 `scripts/`로 옮길 것.
