## 3. 제안

1. **범용 목록 파서 하나 + 사이트별 목록 주소 설정**
   - 이번 점검에 쓴 방식("날짜가 가까이 붙은 링크 = 글 행")으로 그누보드·자체 구조·대화·팔달·SK청솔 같은 서버 렌더링 게시판을 한 파서로 읽는다
   - anyboard는 은평용 코드를 일반화, JSON API(동탄)만 전용 파서
   - 사이트마다 필요한 건 `목록 주소`(+ 필요하면 인증서 예외)뿐 → `docs/gyeonggi/gyeonggi_centers.yaml`
   - 이 파서로 서울 복지관 7곳도 옮기면 출처 목록 통합(구조 점검 1번)과 함께 정리된다
2. **앱 쪽을 먼저 정해야 함** (수집보다 앞)
   - 지금 앱의 지역은 서울 구 단위 칩·체크 목록(이미 13개). 경기 31개 시·군을 붙이면 **시·도 → 시·군·구 2단계 선택**이 필요
   - 서버는 경기 공고를 `all` 토픽에도 보내므로, 지역을 고르지 않은 서울 사용자에게도 경기 알림이 간다 → `all`의 의미(서울 전체? 전국?)를 정해야 함
3. **1차 범위 제안**: 읽힌 곳부터 — 수원(SK청솔·팔달·서호), 성남(중원), 화성(동탄), 고양(대화), 용인(기흥), 부천(포털 4기관), 파주 = 12기관 → 수집·판정 품질을 본 뒤 69곳으로
4. **목록 확보**: 경기도노인종합복지관협회 회원기관 페이지와 한국시니어클럽협회 「시니어클럽 찾기」(경기)를 사람이 열어 이름·홈페이지를 옮기거나(가장 빠름), 시청 누리집을 시마다 확인
5. **시니어클럽**: 노인일자리 모집(11~12월이 모집 철)이 몰리는 곳. 목록은 협회 게시판이 막혀 못 받음. 부천시니어클럽만 부천 포털로 확인 → 위 4번과 함께

## 4. 점검 방법 메모
- 점검 스크립트(세션 임시 폴더): 홈페이지 → 대문 따라가기 → '공지·소식·모집' 링크 후보 → 날짜가 붙은 링크 수로 게시판 판정 → 최근 30일 글 수·규칙 필터 제외 수
- 요청 사이 1초, 차단(403)은 우회하지 않음
- 2차 점검(같은 날): 남은 5곳은 공지 게시판 주소를 직접 지정해 다시 읽음. 월-일만 표시하는 목록(그누보드 등)은 올해 날짜로 해석
